# AI 生图/生视频工具站 — 需求文档 (PRD)

版本：v0.1 draft ｜ 日期：2026-08-24

---

## 1. 项目背景与目标

打造一个**面向个人创作者、设计师、内容营销与开发者**的在线 AI 生成工具站，覆盖文生图、图生图、多图合成、视频生成，并内置提示词优化能力。

核心产品原则：
- **纯前端 / 无自建后台**：不做管理后台、不做用户账号体系、不落库存储用户数据。
- **BYOK（Bring Your Own API Key）**：用户自行填入 Agnes AI 的 API Key，由用户自己的账号额度承担调用成本，本站不代理计费、不加价转售。
- **可一键部署**：代码可直接部署到 Cloudflare Pages / Vercel / Netlify 任一平台，开箱即用。
- **专业精美的现代化界面**：对标 Midjourney / Leonardo.ai / Runway 等主流 AI 生成工具的产品体验水准。

模型能力由 Agnes AI 提供（详见 [API接口文档.md](API接口文档.md)）：文本模型 `agnes-2.5-flash`、图像模型 `agnes-image-2.1-flash`、视频模型 `agnes-video-2.5-flash`。

## 2. 目标用户与场景

| 用户画像 | 典型场景 |
|---|---|
| 自媒体 / 内容创作者 | 快速生成配图、短视频素材，需要多图合成做封面拼图 |
| 设计师 / 电商从业者 | 产品图生成与风格化编辑（图生图）、批量出图对比不同参数 |
| 独立开发者 / 极客 | 已有 Agnes API Key，想要一个好用的可视化调试台，替代裸写 curl |
| 普通兴趣用户 | 想体验 AI 绘画/视频但不想学复杂提示词，依赖"提示词优化"降低门槛 |

## 3. 核心功能需求

### 3.1 文生图（Text-to-Image）
- 输入文本提示词，选择尺寸档位（1K/2K/3K/4K）与宽高比（1:1/3:4/4:3/16:9/9:16/2:3/3:2/21:9）。
- 支持一次生成结果预览、下载（PNG）、加入历史画廊、收藏。
- 支持"重新生成"（沿用同参数换种子/微调 prompt）与"再编辑"（把当前结果作为图生图的输入图，无缝转入下一步创作）。

### 3.2 图生图（Image-to-Image）
- 支持本地上传图片（拖拽 / 点击选择 / 粘贴剪贴板图片）或从历史画廊中选取已生成的图作为输入。
- 输入图在前端转换为 Base64 Data URI 后随请求发送（不依赖外部图床）。
- 提示词描述"要如何改变这张图"，支持保留构图/仅改风格等预设提示词模板。
- 参数与文生图一致（尺寸、比例）。

### 3.3 多图合成（Multi-image Composition）
- 支持一次上传/选取 2～3 张图片（UI 默认引导上限 3 张，超过 3 张给出"第4张起可能产生额外费用"的提示，但不强制拦截，尊重用户选择）。
- 提示词描述"如何组合这些图"，提供常见预设（角色融合、场景合成、风格迁移拼接等）。
- 图片可排序（决定在提示词中的引用顺序 `<Picture 1>` `<Picture 2>` …），并在缩略图上标注序号。

### 3.4 视频生成（Text-to-Video / 图控视频）
覆盖 Agnes Video 三种模式：
- **文生视频**（`text`）：纯提示词生成。
- **首尾帧控制**（`keyframe`）：上传首帧、尾帧图片，描述过渡动作。
- **图片参考生成**（`reference`）：上传最多 5 张参考图，保持角色/风格一致性进行动作生成。

通用参数：时长（4～12 秒滑块）、宽高比（决定输出像素，size 固定 720P）、随机种子（可选，用于复现结果）。

**异步任务管理**：创建任务后前端需展示任务卡片（缩略状态：排队中/生成中/已完成/失败），后台以 1～2 秒间隔轮询状态，完成后自动出现视频预览播放器并可下载；用户可在生成过程中继续做其他创作，任务在"任务中心"里持续跟踪，不阻塞主界面；失败任务展示错误原因（如参数超限）并允许一键修正后重试。

### 3.5 提示词优化（Prompt Enhancer）
- 调用文本模型 `agnes-2.5-flash`，将用户的简短/中文描述改写为更适合生图/生视频模型的专业提示词（补充光影、构图、镜头语言、风格关键词等）。
- 在文生图、图生图、多图合成、视频生成四个创作面板中都提供"一键优化"按钮，优化结果以可编辑文本展示，用户确认或再调整后才真正提交生成，**不自动静默替换原文**。
- 支持自定义系统提示词模板（如"电影感摄影风格"“扁平插画风格”“产品摄影风格”等预设风格包，用户也可自建/编辑模板）。
- 支持流式输出（打字机效果），优化过程可随时停止。

### 3.6 模型与 API Key 配置中心
- 独立"设置"页面/抽屉，用户填入 Agnes API Key、可选自定义 Base URL（默认 `https://api.agnes-ai.cn/v1`，为将来兼容其它 OpenAI 协议服务商预留）。
- Key 仅保存在浏览器本地（见 4.3 数据隐私），提供"测试连接"按钮验证 Key 有效性。
- 支持功能开关与默认参数配置：默认图片尺寸/比例、默认视频时长、是否默认开启提示词优化、Thinking 模式开关等，作为"功能配置项"满足用户需求中的可配置能力。
- 未配置 Key 时，创作按钮置灰并引导用户先去设置页填写，不做任何服务端代理计费的"免费额度"。

### 3.7 历史记录与画廊
- 本地（IndexedDB）保存生成历史：缩略图、完整参数（可一键"复用参数"再次生成）、生成时间、所属功能类型。
- 支持按类型筛选（图片/视频）、收藏、删除、批量下载、清空历史。
- 历史记录仅存本地浏览器，不上传服务器；提供"导出/导入历史"（JSON）以便用户自行备份或换设备迁移。

### 3.8 任务与状态反馈
- 统一的生成进度反馈：文本流式打字、图片同步等待骨架屏、视频异步轮询进度条。
- 错误提示分类清晰：Key 无效/额度不足、参数非法（如视频 size 非 720P、图片超过5张）、网络/超时、服务端错误，均给出人话文案与可能的解决建议。

## 4. 非功能需求

### 4.1 部署与技术约束
- 产出为可直接部署到 **Cloudflare Pages / Vercel / Netlify** 的项目；静态前端 + 各平台原生的 Edge/Serverless Function（用于 API 代理转发，见《网页设计文档》技术架构章节）。
- 不依赖自建数据库、不依赖需要长期运行的独立后端服务，符合"无管理后台"的定位。

### 4.2 无管理后台
- 不做登录注册、不做用户体系、不做后台数据统计看板。
- "配置"即代替"后台"：所有可配置项通过前端设置面板暴露给终端用户自己调整，配置保存在用户本地。

### 4.3 数据隐私与密钥安全
- API Key **只允许**存储在用户浏览器本地（localStorage/IndexedDB），建议做简单混淆/加密存储（如 WebCrypto 对称加密 + 仅本机可用的派生密钥），并在 UI 上明确告知"密钥仅保存在你的浏览器中，不会上传到我们的服务器"。
- 若架构上引入 Edge Function 代理（用于规避 CORS/统一流式转发），代理层**不得记录、不得持久化**用户的 Key 或生成内容，仅做请求透传（Stateless Proxy）。此约束需在设计文档的架构方案中体现并在实现时可审计。
- 生成结果的图片/视频 URL 来自 Agnes 官方存储（如 `storage.googleapis.com/agnes-aigc/...`），下载/展示时需注意链接有效期，长期保存建议引导用户下载到本地。

### 4.4 性能与体验
- 首屏加载快（静态资源 CDN 分发），生成类操作要有清晰的等待反馈，杜绝"卡死无响应"的观感。
- 视频轮询需做好节流与页面不可见时的降频（`visibilitychange`），避免不必要的高频请求。

### 4.5 安全
- 严格的输出转义，防止用户输入/AI 返回内容导致 XSS。
- 合理的 CSP（Content-Security-Policy），限制脚本与图片/视频来源白名单。
- 全站 HTTPS（三大平台默认提供）。

### 4.6 国际化与可访问性
- 默认简体中文界面；文案与组件结构预留 i18n 扩展空间（非 MVP 必须）。
- 关键交互（上传、生成、下载）需支持键盘操作与基础屏幕阅读器标签（aria-label）。

### 4.7 响应式与兼容性
- 桌面优先，同时完整适配移动端（工作台需要有合理的移动端布局重排，而非简单缩放）。
- 兼容主流现代浏览器最新两个大版本（Chrome/Edge/Safari/Firefox）。

## 5. 信息架构 / 页面清单

1. **首页 / Landing（可选，亦可直接落地工作台）**：产品介绍、核心能力展示、"开始创作"入口引导去设置 Key。
2. **创作工作台（主功能页）**：顶部/侧边 Tab 切换「文生图｜图生图｜多图合成｜视频生成」，中心为提示词与参数输入区+结果预览区，集成"提示词优化"入口。
3. **任务中心**：进行中/已完成的视频异步任务列表（也可作为工作台内的抽屉/浮层，不必单独路由）。
4. **历史画廊**：网格化展示历史生成结果，支持筛选/收藏/复用参数/下载/删除。
5. **设置中心**：API Key 与 Base URL 配置、默认参数、功能开关、数据管理（导出/导入/清空本地数据）。
6. **关于/帮助**：模型能力说明、常见问题、指向 Agnes 官方文档的链接。

## 7. 技术栈建议（详见设计文档）

- 前端框架：React + Vite + TypeScript + TailwindCSS（+ shadcn/ui 组件库），适配三大平台的静态构建产物最成熟。
- 代理层：各平台原生 Function（Cloudflare Pages Functions / Vercel Edge Functions / Netlify Functions）承担同一份轻量转发逻辑。
- 本地存储：localStorage（配置项/Key）+ IndexedDB（历史画廊，容量更大且支持结构化查询）。

## 8. MVP 范围与迭代规划

**MVP（第一期，必须完成）**
- 文生图、图生图、多图合成、文生视频/首尾帧/参考视频三模式
- 提示词优化（Chat Completions，流式）
- API Key 设置与本地存储、测试连接
- 历史画廊（本地）、任务中心（视频轮询）
- 响应式布局、错误处理与基础 a11y

**二期（体验增强，非 MVP 阻塞项）**
- 提示词模板/风格包的自定义与分享（本地导入导出）
- 图片对比滑块（原图 vs 生成图）
- 批量生成 / 参数矩阵对比（如同时跑 4 组不同 ratio）
- 深浅色主题切换
- 多语言界面

**暂不做**
- 任何形式的用户账号体系、后台管理、服务端计费与转售

## 9. 风险与开放问题

1. **CORS 是否开放【需联调验证】**：若 `api.agnes-ai.cn` 不支持浏览器直连 CORS，则必须依赖 Edge Function 代理；这决定了架构复杂度，需在开发前用真实 Key 做一次浏览器端 fetch 验证。
2. **视频任务查询接口的完整响应字段未在官方文档给出**，需要联调实测后补全解析逻辑，做好未知字段的容错。
3. **限时免费定价**存在policy变化风险，产品文案需要做"价格可能调整"的免责提示，避免用户误解。
4. **图生图/多图合成的输入图要求公网 URL 或 Base64**：本地上传统一走 Base64，需关注 Base64 体积对请求大小与延迟的影响（必要时前端做压缩/尺寸限制）。
